# React Developer Toolkit

A VS Code toolkit for detecting common React, JavaScript, and TypeScript code issues.

## Features

🚧 Currently under development.

Planned features:

- Detect unnecessary `console.log` statements
- Detect `debugger` statements
- React `useEffect` dependency analysis
- Detect unused code
- React and JavaScript/TypeScript diagnostics

## Requirements

- Visual Studio Code 1.125.0 or later
